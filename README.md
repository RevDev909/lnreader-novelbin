# NovelBin test build

Test build of the NovelBin plugin for LNReader issue #2733 (chapter content fails to load).

This build sends browser-like request headers so novelbin.com stops returning 503 for the app's default user agent. Version 2.3.4.

Install in LNReader: Settings -> Repositories -> add the raw plugins.min.json link from this repo, then Browse -> install NovelBin.
